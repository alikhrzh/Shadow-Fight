lscd# ShadowCoach — пошаговый образовательный AI-тренер

ShadowCoach — образовательный прототип. Он анализирует ограниченный набор визуально
измеримых признаков по одной камере. Тёмный спортивный интерфейс, локальный анализ
движений и объяснения NVIDIA NIM помогают последовательно отрабатывать технику.

## Запуск

Нужен Node.js 22.12+. Рабочий проект находится в **unified**, а не в корне репозитория:

```sh
cd unified
npm ci
npm run model:download
npm run dev
```

Откройте адрес из терминала. Если порт 5173 занят, Vite выберет следующий.
`model:download` проверяет SHA-256 уже существующей модели; скачивает официальную
MediaPipe Full только при необходимости. Камера требует localhost или HTTPS.
На телефоне обычный HTTP по адресу компьютера в локальной сети не подходит.

`npm run dev` запускает и интерфейс, и локальный `/api/coach-feedback` на одном
адресе. Дополнительный сервер для разработки не нужен. Без API key приложение
полностью работает с локальными подсказками. `npm run preview` показывает только
production-файлы: без serverless API AI-разбор перейдёт к локальному fallback.

## Урок и одна попытка

1. Выберите стойку: orthodox — левая нога впереди; southpaw — правая.
2. Выберите джеб, кросс или передний боковой. Джеб и боковой выполняются передней
   рукой, кросс — задней. Анатомическая рука не меняется из-за зеркальной камеры.
3. Посмотрите встроенный видеоурок Tony Jeffries. Рядом доступны русские ключевые
   пункты и ссылка на YouTube. При недоступном видео текстовый урок остаётся рабочим.
4. Нажмите «Перейти к практике». Только теперь запрашивается камера без микрофона.
5. Покажите голову, плечи, локти и обе кисти; проверьте скелет и подсказки положения.
6. Поднимите обе руки над головой примерно на секунду или нажмите «Я готов».
7. Во время 3 → 2 → 1 опустите руки к подбородку. Замрите для калибровки защиты.
8. После «Защита зафиксирована» и «БЕЙ!» выполните ровно один выбранный удар и
   верните руку в защиту. Поднятие и опускание рук перед ударом не оцениваются.
9. Сразу появится локальный результат: балл, надёжность, компоненты и замечания.
   Оранжевые суставы относятся к завершённому удару, а не к текущей позе.
10. NVIDIA добавит краткое русское объяснение. Балл остаётся локальным.
11. Поднимите руки для повтора или нажмите «Повторить». Для выхода покажите крест
    предплечьями у груди примерно на 1,4 секунды или нажмите «Выбрать другой удар».

Три управляющих движения для демонстрации: **руки вверх — запуск; выбранный
боксёрский удар — основное действие; крест руками — выход**. Жесты имеют шкалы
удержания, сглаживание во времени, hysteresis, допуск короткого пропуска и cooldown.
Крест отключён во время countdown, калибровки, удара и анализа. Кнопка выхода
доступна во время практики; во время countdown можно отменить отсчёт.

Вторая попытка автоматически не начинается. На повторе создаётся новый `attemptId`.
Выход и переключение вкладки выключают дорожки камеры и worker. Продолжение —
только вручную через урок. Защита ожидается максимум 10 секунд; при отсутствии
движения через 8 секунд предлагается повтор без выдуманного балла.

## NVIDIA NIM и fallback

Скопируйте `unified/.env.example` в `unified/.env.local` и задайте серверный ключ
локально или в Environment Variables проекта Vercel. Не отправляйте ключ в чат.

```dotenv
NVIDIA_API_KEY=
NVIDIA_MODEL=meta/llama-3.3-70b-instruct
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
```

Ключ не должен иметь префикс `VITE_`. Реальные `.env` игнорируются Git.
Frontend обращается только к `/api/coach-feedback`. Сервер обращается к NVIDIA
`/v1/chat/completions`, выбирает модель и формирует system prompt. Клиент не может
передать свою модель, URL или prompt. [Официальный endpoint NVIDIA](https://docs.api.nvidia.com/nim/reference/llm-apis).

В NVIDIA отправляется allowlist: тип удара, стойка, локальный балл, компоненты,
коды/тексты нарушений, severity и агрегированные числовые метрики. Поддерживается
необязательное обезличенное сравнение баллов; текущий интерфейс его не отправляет.
Ненадёжные попытки в NVIDIA не отправляются. Видео, изображения, кадры, landmarks,
координаты, canvas, аудио и персональные данные в payload не входят.

Сервер проверяет POST, JSON Content-Type, Origin, размер до 12 KB, поля и коды.
Есть базовый лимит 8 запросов в минуту на IP на экземпляр функции. Ответ модели
проверяется по семи полям и ограничениям длины; допускается один повтор для
исправления JSON. Общий серверный timeout — 14 секунд, клиентский — 18 секунд.
API key, полные payload и ответы не логируются.

Нет ключа, баланс исчерпан, 402/422/429/500, timeout, пустой или невалидный ответ —
появится «AI-разбор сейчас недоступен. Показываем локальный анализ техники».
Результат, камера и прогресс сохраняются; доступен повтор. Старые ответы после
повтора или выхода игнорируются. Проверка JSON не гарантирует точность смысла
AI-совета: локальные нарушения всегда остаются рядом для сравнения.

## Режим «ошибка» для жюри

MediaPipe распознаёт точки тела. Собственная логика ShadowCoach вычисляет измеримые
признаки движения. Локальные правила находят конкретные технические ошибки.
NVIDIA AI превращает подтверждённые метрики в понятное объяснение. Если NVIDIA
недоступна, пользователь всё равно получает локальную конкретную подсказку.

Покажите, например, опущенную свободную руку или отсутствие возврата; обсуждайте
только реально выданные замечания. При плохой видимости показывается ненадёжная
попытка без балла — это ограничение качества данных, а не ошибка техники.

## Прогресс и приватность

Для каждого удара localStorage содержит количество надёжных попыток, последний,
лучший и средний балл, дату и последние основные коды ошибок. «Очистить прогресс»
требует явного подтверждения. Недоступное хранилище не блокирует тренировку.

Видео обрабатывается на вашем устройстве и не отправляется на сервер.
Для AI-подсказки в NVIDIA отправляются только обезличенные числовые метрики и
найденные технические ошибки. YouTube загружается только на этапе урока через
`youtube-nocookie.com`; это отдельный внешний сервис. Видео с камеры не записывается.

## Проверки и структура

Из `unified`:

```sh
npm test
npm run test:parity
npm run build
npx playwright install chromium
npx playwright test
```

Браузерные тесты используют порт 5187 (`SHADOW_TEST_PORT` переопределяет), искусственную
камеру и mocks NVIDIA. Отдельные проверки запускают настоящую локальную модель на
пустом изображении/искусственном видео. Физическая камера и настоящий NVIDIA API
для тестов не нужны. Тестовый сервер всегда получает пустой NVIDIA_API_KEY.
Сборка проверяет отсутствие приватных файлов, серверных переменных и известных
секретов в публичных файлах.

- `apps/web/src/lessons`: конфигурация трёх роликов и текстовые уроки.
- `apps/web/src/training`: reducer, управление попыткой, countdown, подготовка.
- `apps/web/src/gestures`: чистая геометрия и временное удержание.
- `apps/web/src/feedback`, `progress`: безопасный payload, результат, история.
- `apps/web/src/components/LiveCamera.tsx`, `pose`: камера, скелет, worker.
- `packages/coach-core`, `shared/config/defaults.json`: исходные правила и пороги.
- `api/coach-feedback.ts`, `shared/feedback.ts`: сервер NVIDIA и проверка данных.
- `tests`, `browser-tests`, `tools/python-reference`: проверки и Python-эталон.

## Перед демонстрацией

Проверьте HTTPS/localhost, разрешение камеры, свет, достаточное расстояние и
свободное место для рук над головой. Пройдите три урока, обе стойки, повтор и
выход. На конкретном телефоне проверьте portrait/landscape, FPS и нагрев.
Проверьте доступ к YouTube и NVIDIA, а также работу без ключа. Не показывайте ключ
или панель серверных переменных при трансляции экрана.

Одна камера не измеряет силу, нагрузку, точную 3D-биомеханику и не гарантирует
правильность техники. Приложение не заменяет тренера, не ставит диагнозы и не
обещает предотвращение травм. Cross подключён к существующим правилам задней руки
и проверен синтетически; реальная валидация кросса ещё необходима. Точность жестов
на разных людях и работа на реальных iPhone/Android требуют ручной приёмки.
Известные ограничения коротких записей live-сегментации сохранены в TESTING.md.
