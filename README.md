# ShadowCoach — unified browser beta

Публичная бета: https://shadowcoach-live-20260929.alikhanrzh6990.chatgpt.site

Итоги и незакрытые проверки: [SUMMARY.md](unified/SUMMARY.md).

Один проект из интерфейса `admit-hack` и правил `shadowcoach-ml` версии 0.1.2.
Камера, MediaPipe Full и анализ выполняются на устройстве пользователя. Сервер
для обработки видео не используется. Микрофон не запрашивается, видео не записывается.

## Запуск

Нужен Node.js 22.12+ (проверено на Node 25.4). Из корня проекта:

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает сервер. Разрешите камеру после нажатия кнопки.
Для телефона используйте опубликованную HTTPS-версию, не обычный HTTP-адрес в локальной сети.
Для сборки: `npm run build`. Публикуется **только** `apps/web/dist/`.

Модель включена в переданную локальную папку. После нового Git-клонирования, если
модель отсутствует, выполните `npm run model:download`: скрипт скачивает официальную
Full-модель и проверяет SHA-256. WASM и worker собираются из зафиксированных зависимостей.

## Первая тренировка

1. Выберите джеб или передний боковой и свою стойку.
2. Поставьте камеру устойчиво; голова, плечи, локти и обе кисти должны быть видны.
3. Нажмите «Начать тренировку», дождитесь модели и замрите в защите на секунду.
4. Выполните один удар, верните руку и задержитесь в защите примерно на секунду.
5. Повторяйте отдельные удары. Комбинации и автоматический выбор типа удара не поддержаны.
6. Завершите тренировку. Можно скачать локальный JSON-отчёт без видео и координат.

При переключении вкладки камера выключается; продолжение запускается вручную.
Смена упражнения, стойки и камеры доступна на паузе. Счётчики относятся ко всей
текущей сессии; «Новая тренировка» очищает их. История хранится только в памяти
страницы, максимум 50 подробных попыток; общие счётчики накапливаются отдельно.

## Структура

- `apps/web/`: React-интерфейс, камера, наложение точек, classic Web Worker.
- `packages/coach-core/`: чистые TypeScript-расчёты и потоковая обработка.
- `shared/config/defaults.json`: общий основной файл порогов.
- `shared/fixtures/`: синтетические контрольные данные, не включаются в сайт.
- `tools/python-reference/`: сохранённый Python-анализатор и его тесты.
- `scripts/`: генерация контрольных данных, сравнение, сборка и аудит публикации.
- `private-data/`: локальные проверки и снимки, игнорируются Git и публикацией.
- `publication/`: отдельная сборка для хостинга; не содержит исходных записей.

Оригинальные `admit-hack` и `shadowcoach-ml`, включая Git-историю друга и датасет,
не изменены. В объединённой копии удалены старые неиспользуемые компоненты-заглушки
и дублирующиеся браузерные нормализатор/сглаживание. Python-проверки сохранены.

## Ограничения

Это прототип, а не подтверждённая тренером диагностика техники. Балл не означает
процент правильности. Одна камера не измеряет силу, нагрузку на суставы или точную
биомеханику. World-координаты — оценки модели, не измерение 3D-камерой.

Браузерный SDK не предоставляет отдельный `presence` каждого сустава. Это явно
обозначено `presence_unavailable`, а не заменено на 1. Браузер проверяет visibility,
геометрию, непрерывность и число людей. Отчёт имеет `confidence_mode: visibility_only_web`.
При сравнении на Python-координатах с настоящим presence сохраняется прежняя проверка.

При обработке медленнее примерно 10 кадров/с появляется предупреждение; длительные
пропуски не превращаются в ошибки техники. Скорость на вашем телефоне нужно проверить.
Апперкоты и кросс пока не доступны в публичном интерфейсе.
