# Публикация на Vercel

Эта задача готовит исходники и конфигурацию; публикация требует отдельного разрешения.
Ранее опубликованная статическая бета в Sites и папка `publication/` не обновлялись.

1. Подключите репозиторий к Vercel и задайте Root Directory: `unified`.
2. Используйте Node.js 22+ и `npm ci`. `vercel.json` задаёт build command:
   `npm run model:download && npm run build`, output: `apps/web/dist`.
3. В Environment Variables задайте NVIDIA_API_KEY, NVIDIA_MODEL и NVIDIA_BASE_URL
   из `.env.example` без `VITE_`. Ключ хранится только на сервере.
4. Vercel обнаруживает `unified/api/coach-feedback.ts` как `/api/coach-feedback`.
   Лимит функции 30 секунд; внутренний дедлайн NVIDIA — 14 секунд на оба обращения.
5. После отдельно разрешённой публикации проверьте камеру по HTTPS, все три урока,
   ответ AI и fallback. Не копируйте весь проект в публичный каталог.

Модель не хранится в Git: build command скачивает официальную Full-модель и проверяет
SHA-256. В статический output входят HTML/CSS/JS, worker, WASM, иконка и модель.
Скрипт audit-build проверяет отсутствие видео, исходных координат, Python, env-файлов,
серверных переменных, тестовых и известных локальных секретов.

Для локальной разработки `npm run dev` обслуживает API через серверный Vite middleware.
`unified/.env.local` читается только серверной конфигурацией. Для `vercel dev` нужен
авторизованный проект Vercel; для обычной локальной работы он не требуется.
Статический `npm run preview` не запускает API — интерфейс использует fallback.

Origin сверяется с host/protocol запроса; внешние CORS-клиенты не разрешены.
Лимит IP в памяти является базовой защитой отдельного warm instance, не глобальной
защитой бюджета. Для открытого высоконагруженного сервиса подключите Vercel Firewall
или общее хранилище лимитов. Это образовательный прототип без авторизации.
Логи endpoint не содержат body, ответа модели, stack trace или секретов.
