# Публикация

Основной проект — обычное статическое приложение. Сборка: `npm ci && npm run build`.
Публичный корень: `apps/web/dist`. В него входят только HTML/CSS/JS, worker, WASM,
иконка и модель. Скрипт `audit-build.mjs` проверяет отсутствие видео, JSONL и Python.

Для текущей публикации используется Sites Hosting. Его отдельный каталог
`publication/` содержит `.openai/hosting.json` с идентификатором сайта и копию
проверенной сборки в `dist/`. В удалённый репозиторий публикации не попадают
`private-data`, исходный датасет, тестовые снимки и Python-окружение.

Обновление сайта: сначала проверить и собрать основной проект; затем обновить
статическую сборку в существующем каталоге публикации и опубликовать новую версию
**того же сайта**. Не создавать новый сайт при каждом исправлении. Сохранённые версии
хостинга позволяют вернуться к предыдущей публикации.

Публичному сайту нужен HTTPS. Камера должна быть разрешена политиками хостинга;
при открытии во встроенном окне без разрешения камеры используйте отдельную вкладку
обычного браузера. Приложение не требует backend API или секретов.

Перед публикацией не копируйте целиком основной проект в публичный каталог.
Не публикуйте локальные отчёты, видео и контрольные координаты. Камера работает
только после явного нажатия пользователем кнопки и разрешения браузера.
